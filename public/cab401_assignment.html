How I Made This Application 7x Faster

I optimised a bioinformatics application that analyses bacterial genomes by comparing genetic similarities. The original implementation was slow, taking 39 seconds to process. Through parallelisation and code optimiation, I reduced the runtime to just 4 seconds—a speedup of nearly 7 times.

Performance Bottlenecks in the Original Code

The original application had several performance bottlenecks:

  • The Bacteria constructor accounted for 58.56% of the total CPU time.
  • The CompareBacteria function accounted for 40.76% of the execution time.
  • File reading and processing were done sequentially, leading to significant delays.

Optimisation Strategies

1. File Reading Optimiation

I optimied the file reading process by loading the entire file into memory in a single operation, reducing disk I/O overhead.


FILE* bacteria_file = fopen(filename, "rb");
fseek(bacteria_file, 0, SEEK_END);
long file_sie = ftell(bacteria_file);
fseek(bacteria_file, 0, SEEK_SET);

char* buffer = new char[file_sie + 1];
sie_t read_size = fread(buffer, 1, file_size, bacteria_file);
buffer[read_sie] = '\0';
